# CertivoIQ Pricing Strategy and Five-Year Planning Model

## Authoritative commercial pricing

CertivoIQ has two annual enterprise license types:

- **Multifamily Enterprise — $65,000 per selected state per year.** Each selected state is a separately licensed state rule pack.
- **PHA — $150,000 per year, flat.**

All currently available platform features are included in the applicable license. CertivoIQ does not publish training or Academy products, certificates, per-file overages, or separately priced API products. Any implementation, migration, custom integration, premium-support, procurement, or legal exception must be separately documented and approved; it must not alter public list pricing without an authorized pricing decision.

This language is authoritative across the public website, billing and invoice workflows, CRM, agreements, email templates, marketing kits, campaign copy, sales collateral, and financial planning.

## Pricing principle

CertivoIQ is priced against enterprise value, compliance workflow scope, portfolio scale, implementation complexity, governance, security requirements, and support obligations—not simply hosting cost.

A potential tax-credit takeback or other compliance loss may be used as factual risk context, but never as a guaranteed loss that CertivoIQ will prevent. Value discussions should also address labor capacity, reduced rework, audit readiness, consistency, traceability, and portfolio visibility.

## Five-year planning method

Financial models must calculate recognized revenue from the actual license mix:

- Multifamily ARR = number of licensed state selections × $65,000.
- PHA ARR = number of PHA licenses × $150,000.
- Total ARR = Multifamily ARR + PHA ARR.

Customer counts alone are insufficient because one multifamily customer may license multiple states. Forecasts must keep customer count, state-license count, PHA-license count, bookings, recognized revenue, churn, commissions, gross margin, operating expense, and cash assumptions separate.

Every forecast is a planning scenario—not a valuation, booked-business representation, accounting conclusion, tax opinion, or guarantee.

## ROI framing

Preferred framing:

**Annual platform value = labor capacity recovered + avoided rework + faster audit preparation + reduced external consulting burden + portfolio visibility + documented risk reduction.**

Use potential recapture, penalties, or findings as risk context only when factually supported for the customer's specific program and circumstances. Do not promise that CertivoIQ eliminates or guarantees avoidance of recapture, fines, findings, or noncompliance.
