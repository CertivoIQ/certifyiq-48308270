# CertivoIQ Financial Model Notes

The detailed editable five-year model is maintained as an investor/management workbook outside the source repository. The base case currently uses the following operating-expense assumptions:

| Year | Operating expense assumption | EBITDA / operating contribution before commission and contingency reserves |
| --- | ---: | ---: |
| 1 | $425,000 | -$215,000 |
| 2 | $1,100,000 | $62,500 |
| 3 | $2,800,000 | $1,100,000 |
| 4 | $6,500,000 | $3,700,000 |
| 5 | $12,000,000 | $9,730,000 |

The model also includes a 10% illustrative commission reserve on recognized revenue and a 5% planning contingency reserve on positive operating contribution. These are planning inputs, not accounting conclusions or tax advice.

The workbook should remain the source for scenario editing; this Markdown file is a concise investor diligence reference only.
